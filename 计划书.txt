任 务 题 目

基于 STC8H8K64U 实验箱的电子手表风格 UI 菜单系统设计

一、 目的与要求
1. 掌握 STC8H8K64U 单片机开发全流程：Keil C51 工程配置（MODP2、寄存器文件、内存模型、无启动文件）、STC-ISP 烧录与上机调试。
2. 掌握 0.96 寸 SSD1306 OLED（128×64）硬件 I2C 驱动：STC8H I2C 模块配置与速率调优（MSSPEED 等待时钟数公式，176kHz→400kHz 提速翻倍）、SSD1306 初始化序列（段重映射/COM 配置/电荷泵）、framebuffer + 列级 diff 局部刷新（只发变化列段）与周期全刷自愈的刷新策略设计。
3. 掌握 16 键 ADC 键盘（电阻分压式）的扫描原理、三态滤波消抖与长按连发处理，实现流畅的菜单导航交互。
4. 掌握 C51 内存管理（IRAM / XRAM / CODE 分段）、中断与定时器（Timer0 20ms 节拍）、I2C 总线容错（超时保护、GPIO 9 脉冲总线恢复、外设重新初始化）等嵌入式可靠性编程技术。
5. 学会移植开源 UI 框架（OLED_UI，Apache 2.0）至 51 平台：C99→C51 兼容性改造（块内声明提升、库函数替换、结构体初始化限制等 39 处），掌握"应用页层 / UI 框架层 / 驱动层 / 平台适配层"模块化分层架构设计方法。
6. 综合运用 ADC（NTC 测温）、UART（串口通信）、蜂鸣器等外设，实现功能完整、界面流畅的嵌入式人机交互系统。
7. 掌握虚拟 OLED 调试方法：USB-CDC 将帧数据发送至 STC-ISP 调试仿真接口虚拟屏，无实体屏完成 UI 逻辑调试。
8. 要求系统运行稳定（总线故障自动恢复）、菜单操作毫秒级响应（静态 80+fps、动画 35fps）、代码规范、注释清晰，并提交完整的课程设计文档，完成上机演示与答辩。

二、 主要任务
1．搭建 STC8H8K64U 实验箱 + 0.96 寸 SSD1306 OLED 的 Keil C51 开发环境，按实验箱官方配置建立工程（MODP2=1、STC8.H、LARGE 模型、无 STARTUP.A51），完成硬件资源盘点与可行性评估。
2．编写 SSD1306 硬件 I2C 底层驱动（STC8H I2C 模块、MSSPEED 速率调优、初始化序列、双后端：实体 I2C / 虚拟 USB-CDC）与 1KB framebuffer，实现列级 diff 局部刷新引擎 + 周期全刷自愈 + 总线自动恢复。
3．移植开源 OLED_UI 框架：完成 C99→C51 兼容性改造（39 处），适配磁贴桌面、多级列表菜单、窗口组件、动画系统（UNLINEAR 插值）、渐隐效果、深浅色主题与中英文字模（裁剪 70KB→56KB、补 29 字、手绘 5 个功能图标）。
4．移植官方 16 键 ADC 键盘扫描算法（256 分档 + 三态滤波），实现 Timer0 20ms 定时节拍，将按键事件接入 UI 状态机（上/下/确认/返回、长按连发）。
5．实现设置页（亮度窗口 0x81 真实调节、深浅色模式 0xA7/A6、帧率显示默认开启）、关于页与页面切换动画（渐隐 + 滑入，~1.5s）。
6．实现 NTC 测温页（ADC 采样 + 161 点查表 + 线性插值）与串口通信页（UART1 115200 行协议、256B 环形缓冲、@ 命令模式）。
7．实现计算器（16 键键盘映射、四则运算）与游戏模块（贪吃蛇、俄罗斯方块、小恐龙）。
8．整机联调与上机实测：按键映射确认、帧率验证（静态 80+fps / 动画 35fps）、总线故障恢复验证、功能逐一验收，整理设计文档与答辩材料。
